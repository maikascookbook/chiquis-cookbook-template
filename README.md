# Chiqui's Cookbook

A clean copy of the upgraded cookbook, with no seeded recipes and no connection to Maika's Supabase project.

SETUP REQUIRED BEFORE USING LOGIN / CLOUD SYNC:
1. Create a Supabase project under Chiqui's own account.
2. Configure its database policies, authentication and image storage (the original project's setup is not contained in this ZIP).
3. Replace YOUR-PROJECT and YOUR-PUBLISHABLE-KEY in BOTH app.js and cookbook-upgrade.js.
4. Upload these files to the root of Chiqui's own GitHub Pages repository.
5. Enable GitHub Pages (Deploy from branch, main, root).

The customization panel currently saves designs locally per browser, not across devices.
The included app icons and illustration assets come from the original design; replace icons if desired.
